# Workflow Engine

A Java 21–based workflow orchestration engine designed to reliably execute
long-running, multi-step business processes.

## Goals
- Durable workflow execution
- Restart-safe state machine
- Clear execution history
- Designed for distributed execution (future)

## Tech Stack
- Java 21
- Spring Boot 3
- PostgreSQL
- Flyway

## Status
🚧 Early development – foundation phase
